# Proyecto Final Integrador: Detección de Fraude en Tarjetas de Crédito
**Diplomatura en Ciencia de Datos y Análisis Avanzado - UTN BA**

## Descripción
Modelo predictivo de Machine Learning (XGBoost y LightGBM) para la detección de operaciones fraudulentas en transacciones financieras.

## Instrucciones de Ejecución
1. El código completo se encuentra en el archivo de Google Colab alojado en este repositorio (`.ipynb`).
2. Para ejecutarlo localmente o en la nube, asegúrese de contar con las librerías necesarias especificadas en el script (`pandas`, `scikit-learn`, `xgboost`, `lightgbm`, `imblearn`).
3. El dataset utilizado ("Credit Card Fraud Detection") se descarga automáticamente mediante `kagglehub`.
